# Prism Dev Pack

This extension pack installs the complete **Prism** suite for SQL and dbt development in VS Code:

1. **SQL Prism (`elambert.sql-prism`)**: Deterministic CTE coloring, vertical CTE scope guides, contextual keyword coloring, and semantic data type highlighting.
2. **dbt Prism (`elambert.dbt-prism`)**: Schema-aware autocompletion, data type icons and badges on hover, and multi-hop Go-to-Definition across CTEs and dbt models.
